Proyecto de Inteligencia Artificial

Visión artificial para monitorear el cultivo

El sistema localiza frutillas en imágenes tomadas desde la perspectiva del robot y reconoce tres estados de madurez. Esto permite registrar cómo se distribuyen los frutos visibles durante un recorrido.

Dataset

Frutilla V4 v1 reúne 7.927 imágenes RGB propias y de fuentes externas. Las anotaciones indican la ubicación y el estado de cada fruto. La exportación de Roboflow usa imágenes de 640 × 640 píxeles con relleno para conservar la proporción.

Ver dataset en Roboflow ↗

Modelo 2 · YOLO11n

El detector devuelve una caja, una clase y una confianza por fruto. Se entrenó con AdamW, tasa inicial de 0,001, lotes de 16 y detención temprana. El mejor checkpoint se obtuvo en la época 41.

Ver pesos y configuración ↗

Características y optimización

Para el clasificador auxiliar se extrajeron tres características HSV de cada recorte: proporción roja, proporción verde y saturación media. La búsqueda en grilla evaluó la regularización y el balanceo de clases en la regresión logística.
